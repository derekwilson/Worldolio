# Support

Support data and scripts needed by Worldolio

- `CurrentBuild` is where the scripts place the built artifacts
- `Data` scripts to build the `worldolio.sqlite` database
- `Maps` world maps used in custom controls
- `Notes` notes on errors and tasks
- `Screenshots` examples of various POC builds
- `Tools` CLI tools from https://sqlite.org/ that were used to build the DB
